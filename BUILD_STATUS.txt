MeshMessage UI-only Flutter build
Firebase, Firebase Authentication and Firestore have been removed from the app dependencies and entry flow.
A standard Android Gradle project scaffold is present under android/.
GitHub Actions validates Dart, runs widget tests and builds a release APK artifact.
Bluetooth and LoRa accessory features are prototype integrations, not certified end-to-end offline mesh messaging.
LoRa radio transmission must remain disabled until the hardware and applicable regional radio configuration are verified.
No successful CI build or hardware test is claimed until GitHub Actions reports success.
